## Project Purpose

Caelus Air is a fictional airline built around the idea that travel experiences should be adventurous and memorable. The goal of this project is to create a two-page website that establishes the brand of Caelus Air, shows what the airline offers, and functions as the airline's main online presence.

Most reputable brands have their own website. Without one, they may lack outreach, credibility, and a clear way to connect with their audience. The purpose of this project is to create a website that is simple to navigate, purposeful, and visually appealing for users. This project also demonstrates planning, building, and reflection skills through a complete project package.

## Project Description

This project will result in a two-page static website for Caelus Air, built with HTML and CSS and stored in a public GitHub repository.

The homepage will introduce the airline with a hero section, a featured destinations section, and a "Why Fly With Us?" section that explains the main idea behind the brand. The About page will describe the concept of Caelus Air, the purpose of the project, and what the website represents.

The two pages will be connected through a consistent navigation bar and styled with a single external CSS file to keep the design unified.

In addition to the website, the project will include a `docs/` folder with three planning documents and a `README.md` file that explains the project. The website may also be deployed using GitHub Pages.

## Desired Results

- A working two-page website that is connected and easy to navigate.
- A single external stylesheet that keeps the design consistent across both pages.
- A public GitHub repository that is organized and professional.
- A `docs/` folder containing `scope.md`, `plan.md`, and `retrospective.md`.
- Clear and readable content that presents the Caelus Air concept in a simple structure.
- All deliverables completed and submitted on time.

## Exclusions

The following items are outside the scope of this project:

- Back-end functionality, databases, or server-side code.
- A real booking or reservation system.
- JavaScript or interactive features.
- More than two HTML pages.
- Real airline data or live flight information.
- External APIs or integrations.
