## PROJECT PURPOSE:

Caelus Air is a fictional airline built around the idea that travel experiences should be adventurous and memorable. The goal of this project is to create and build a website consisting of two pages that establishes the brand of Caelus Air, shows what the airline offers, and is the airline's main online presence. 
Most reputable brands have their own website. Without it, they would lack outreach and credibility and wouldn't have any means of connecting with their audience. The purpose of this project is to create a website that is simple to navigate, purposeful, and aesthetically pleasing for the user. This project will also show my planning, building, and reflecting abilities on a complete project.


---

## PROJECT DESCRIPTION:

This project will result in a two-page static website for Caelus Air, built using HTML and CSS and stored in a public GitHub repository.

The main page will introduce the airline, including a hero section, a featured destinations section, and a“Why Fly With Us” section that explains the main idea behind the brand. The About page will describe the concept of Caelus Air, its purpose, and what it represents.

The two pages will be connected via a consistent navigation bar and styled using a single external CSS file to keep everything visually consistent.

Besides the actual website, the project will include a docs folder with three planning documents and a README.md that explains the project. The site may also be deployed using GitHub Pages.

## EXCLUSIONS:

The following are not included:

- Any back-end functionality, databases, or server-side code  
- A real booking or reservation system  
- JavaScript or interactive features  
- More than two HTML pages  
- Real airline data or live flight information  
- External APIs or integrations
